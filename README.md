## 📘 Phase Breakdown

### Phase 1 — Core JavaScript & Node
- **Concepts:** ES6+, Functions, Async/Await, Node runtime, HTTP basics  
- **Deliverables:** CLI apps, modular JS, minimal HTTP server  
- **Checkpoints:** Scripts run cleanly, server returns “Hello World”

---

### Phase 2 — Express.js & REST APIs
- **Concepts:** Routing, Middleware, CRUD, Validation, Swagger docs  
- **Deliverables:** /api/notes CRUD, Zod/Joi validation, Swagger UI  
- **Checkpoints:** CRUD tested via Postman, invalid requests rejected, docs render

---

### Phase 3 — MongoDB & Mongoose
- **Concepts:** Schemas, Models, Indexes, Aggregations, Seed data  
- **Deliverables:** Note schema, aggregation pipeline, seed scripts  
- **Checkpoints:** Notes persist, indexed queries faster, stats endpoint works

---

### Phase 4 — React Development
- **Concepts:** Components, State, Effects, Router, Context, Performance  
- **Deliverables:** BookList UI, controlled forms, routing, accessibility fixes  
- **Checkpoints:** UI renders, forms validated, Lighthouse ≥90 accessibility

---

### Phase 5 — MERN Integration
- **Concepts:** API ↔ React integration, Auth UI, Protected routes, Error handling  
- **Deliverables:** Axios client, CRUD integration, JWT login/register, architecture docs  
- **Checkpoints:** End‑to‑end CRUD works, token stored securely, unauthorized access blocked

---

### Phase 6 — Security
- **Concepts:** JWT, RBAC, CORS, XSS prevention, Threat modeling  
- **Deliverables:** Auth endpoints, password hashing, role‑based routes, sanitization  
- **Checkpoints:** No plaintext passwords, role checks enforced, security checklist documented

---

### Phase 7 — Uploads, Realtime & Jobs
- **Concepts:** File uploads, Socket.IO, Background jobs, Moderation  
- **Deliverables:** Multer uploads, live comments, BullMQ jobs, toxic content filter  
- **Checkpoints:** Image stored, realtime comments broadcast, jobs processed

---

### Phase 8 — Testing & Quality
- **Concepts:** Unit tests, Integration tests, Linting, Coverage, QA review  
- **Deliverables:** Jest + Supertest tests, RTL frontend tests, ESLint + Prettier  
- **Checkpoints:** ≥80% coverage, CI badge visible, hooks enforce quality

---

### Phase 9 — DevOps & Cloud
- **Concepts:** Docker, CI/CD, Cloud hosting, Observability  
- **Deliverables:** Dockerfile, docker‑compose, GitHub Actions CI, Vercel/Render deploy  
- **Checkpoints:** API serves via Docker, CI passes, public URLs live, runbook documented

---

### Phase 10 — AI Integration
- **Concepts:** LLM APIs, Prompt engineering, Embeddings, RAG, ToolCalling  
- **Deliverables:** OpenAI API setup, review assistant UI, semantic search, RAG help center  
- **Checkpoints:** AI responses stable, embeddings stored, semantic matches returned, citations included

---

### Phase 11 — Capstone: AI‑Powered Book Discovery Platform
- **Features:**  
  - MERN CRUD for books  
  - JWT Auth + RBAC  
  - Realtime comments (Socket.IO)  
  - AI review assistant (LLM)  
  - Semantic search with embeddings  
  - RAG help center with citations & toolcalling  
- **Deliverables:** Final README, architecture diagram, demo video, portfolio write‑up  
- **Checkpoints:** Demo recorded, portfolio published, confident system design walkthrough
