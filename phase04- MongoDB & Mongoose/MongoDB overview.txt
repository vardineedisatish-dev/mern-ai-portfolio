
Introduction
MongoDB is a document-oriented NoSQL database that stores data in flexible JSON-like documents. Mongoose is a Node.js library that adds structure and validation to MongoDB by using schemas and models. In this phase, we’ll cover schemas, models, indexes, aggregations, and seed data — all the essentials for building a reliable backend.

Key Concepts
Schemas  
Define the structure of documents (fields + types). Think of them as blueprints.

Models  
Built from schemas. They’re the objects we use to interact with MongoDB (CRUD operations).

Indexes  
Improve query performance. Without indexes, MongoDB scans all documents. With indexes, queries jump directly to relevant data.

Aggregations  
Pipelines that process and transform data. Useful for grouping, filtering, and calculating statistics.

Seed Data  
Sample data inserted into the database for testing. Helps validate schemas, queries, and endpoints before production.

Workflow
Define a schema for notes.

Create a model from the schema.

Insert seed data (sample notes).

Add indexes to speed up queries.

Write aggregation pipelines for stats.

Verify deliverables:

Notes persist in DB.

Indexed queries run faster.

Stats endpoint returns correct results.
 Examples
Schema
js
const noteSchema = new mongoose.Schema({
  title: String,
  content: String,
  createdAt: { type: Date, default: Date.now }
});
Model
js
const Note = mongoose.model('Note', noteSchema);
Index
js
noteSchema.index({ title: 1 });
Searching by title is now faster.

Aggregation
js
Note.aggregate([
  { $group: { _id: null, totalNotes: { $sum: 1 } } }
]);
Counts total notes in the database.

Seed Script
js
const seedNotes = [
  { title: "First Note", content: "Learning MongoDB!" },
  { title: "Second Note", content: "Schemas are cool." }
];
Note.insertMany(seedNotes);
Deliverables
Note schema → Defined and working.

Aggregation pipeline → Returns stats (e.g., total notes).

Seed scripts → Insert sample notes.

Checkpoints
Notes persist correctly in MongoDB.

Indexed queries show noticeable speed improvement.

Stats endpoint (via aggregation) returns expected results.

Key Takeaways
Schemas = structure.

Models = database interaction.

Indexes = performance boost.

Aggregations = analytics.

Seed data = testing ground.
