Structured errors:
Structured error mean representing errors in a consistent, machine-readable, predictable format instead of plain text.
A normal(unstructured) error look as:
Something went wrong!
A structured error looks like:
{
“error” : “UserNotFound”
“message”: “user with id 42 not found”,
“status”: 404,
“timestamp”: “2026-01-28T10:00:00.000Z”,
“path”: “/users/42”
}
Structured error contains:
Error – A short code like UserNotFound,ValidationError
Message – Human- readable explanation
Status     -  HTTP status(e.g, 400,404,500)
Timestamp – when it occurred
Path      -   API route where it failed
Details   - Extra info (optional)
